- `extracted/faq.txt`、`extracted/task-map.txt` 由 PDF 文本层按页提取，未作内容改写；可能含特殊 Unicode 字形或换行。
- 规则 PDF 为扫描件，文本层提取结果为空；阅读原始 PDF 图像，已核对的要点记录于 [规则摘要](../docs/rules-summary.md)。没有把空文本当作完整转录。
