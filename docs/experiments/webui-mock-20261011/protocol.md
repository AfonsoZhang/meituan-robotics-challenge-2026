# 本地 Web UI Mock 验证协议

此记录仅验证界面与 HTTP Mock 数据契约。界面完成数不是抓取成功率；设备布尔值与证据等级均为样例。

1. 从仓库根目录运行 `python3 -m webui.server`，默认 127.0.0.1:8767；原始日志见 inputs.json。
2. 执行 `python3 -m unittest discover -s webui -p 'test_*.py' -v`、demo/robot 原有 unittest；源码与环境指纹见 inputs.json，输出完整保留。
3. 打开页面，确认空任务、未连接相机和 Mock 标志。序列输入重复颜色，应本地拒绝；改为绿/蓝/红样例，提交后禁用重复按钮、刷新恢复 task ID 与口令、暂停时冻结显示、恢复后按后端显示 3/3。
4. 基础任务逐一触发识别失败 110、超时 220、普通取消及未确认停稳 520。普通取消结果出现时仍需等待独立停稳；未停稳场景禁止新任务，补发 Mock 停稳反馈后可重新操作。
5. 切换过期/缺失样例，显示未知并拒绝新任务。阻断一次 `/api/snapshot` 请求，页面断流后禁用操作；取消阻断后恢复且任务数不变。读取旧记录不覆盖当前任务。
6. 查看 task/goal ID、事件与结果，HTTP 导出返回 200 和 attachment 文件名。浏览器下载事件超时单列，不据此认定下载文件已落盘。
7. 检查 320/390/768/1024/1440 像素宽度无页面溢出；留存桌面、运行中与手机截图。最后完成一轮蓝色到 T0 的正常样例；失败记录不删。

浏览器工具输出摘录见 browser-checks.json，包含先前标签定位失败和下载事件超时。注入网络失败导致的 net::ERR_FAILED 为预期；生产连接、相机、ROS、NUC、实机均未测试。事件时间为处理/写盘时刻，非真实设备时钟。

使用 OpenAI Codex 协助编写并执行以上检查。界面来源与上游接口引用见 webui/provenance.json。
