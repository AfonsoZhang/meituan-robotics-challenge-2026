## 方案一：钩取提手

2026-09-06 用户明确“使用钩子”（USER-EE-20260906-01），随后新增“方案二：使用吸盘，侧面吸附”（USER-EE-20260906-02）。钩取提手保留为方案一，与侧吸方案并列评估，最终取舍尚无试验依据。原先两指夹持仅为更早的工程候选；钩具是否已有、材料、结构和尺寸尚未确认。

建议先评估固定被动钩：钩柄位于提手一侧，承托舌沿 y 方向从前或后方穿过开口，位于横梁下方；远端上翘钩尖越过横梁后再上抬承托。J/L 形轮廓及止退细节属于待验证设计，不是用户已确认的具体结构。

| 图示几何 | 对钩具的约束 |
| --- | --- |
| 孔口净高约 20 | 核验穿孔部分在进、退钩姿态下的完整竖向包络，包含承托舌厚度、上翘尖和上下余量；只检查杆件厚度不足以判断可通过 |
| 孔口宽约 50 | 钩具穿孔部分的横向宽度及运动包络须留出左右定位、朝向和圆角余量；50 依赖立柱对称假设，需先核验实际孔宽 |
| 横梁前后厚约 26 | 钩柄与远端上翘尖之间的有效内喉深须容纳实际梁厚并留间隙；穿入行程须让钩尖越过远侧边缘，不能直接令行程等于 26 |
| 横梁竖高约 10 | 检查承托后钩尖与横梁的有效止退搭接以及下降后的退出空间，不据此规定钩尖必须高于 10 |

对“水平承托舌＋上翘尖”的固定姿态候选，可用以下工程约束检查可逆性：实测孔高为 `H`，舌厚为 `t`，上翘尖高于承托面的高度为 `h`，上下余量为 `c_top`、`c_bottom`，应满足 `t + h + c_top + c_bottom < H`。电池已落台并卸载后，从承托面原接触位置下降 `Δ`，须存在 `h + c_top < Δ < H − t − c_bottom`，才能使钩尖低于横梁底缘且舌底不撞本体顶面。这些是候选几何的检查式，不是加工尺寸或已验证运动指令；实际圆角、倾斜和工具扫掠包络仍需建模。

建议动作顺序：到孔口外预备位 → 对准开口水平穿钩 → 上抬承托并确认电池离台 → 稳定搬运 → 放至目标面并卸载 → 下降至可退钩高度 → 沿进钩通道水平退出 → 到观察位复核。放置位姿须同时留出退钩通道；工具尚在孔内时直接抬走会再次带起电池，未卸载就后退可能拖动电池。

单钩吊挂时电池可能摆动、倾斜和绕承托处转动，机器人末端朝向不能直接当成电池朝向。承托位置优先接近横梁中部，并核验与实测重心的关系；依据实测摆动与滑移限制加速度，放置及脱钩后重新测量电池实际位置。远端上翘尖仅限制相应方向的退出，不能视为所有方向的锁定；无上翘端的普通 L 形托舌也不能直接当成具备该止退作用。钩尖止退效果、提手强度、钩具挠度和表面接触情况须实物验证；本节不指定材料、截面或承载能力。

D435i 继续按末端安装设计，固定在法兰转接件或钩具固定座上。相机视线、钩柄/钩尖包络和线缆共同核验；定义可重复标定的钩具承托参考点为 TCP，并保存钩尖相对该点的偏移。控制流程按运动与视觉确认推进，不假定存在电动开合、夹持力控制或夹爪状态接口。

实物验证顺序建议为：测量孔口与钩具 → 空载验证进钩和退钩 → 在已核对承载条件下试提 → 观察摆动和滑移 → 验证落台、卸载与脱钩 → 完整序列搬运。钩具未验证到位期间可先开展视觉与标定准备。

## 方案二：吸盘侧面吸附

用户确认的是新增侧吸路线，尚未指定吸盘数量、型号或真空设备（USER-EE-20260906-02）。按图示直立姿态，候选吸附面为本体的竖直侧面：前/后面的名义外包络为 70×50，法向沿 y；左/右面为 80×50，法向沿 x（BATTERY-DRAWING，由本体三向尺寸组合，单位暂按 mm）。这些包络不是完整可密封平面；侧边及上下棱边圆角、接缝、纹理和制造误差都会影响可用区域，不能将 R2 外推到全部棱边。

工程上先在侧面连续平整区域选择吸附点，核验吸盘受压后的唇边及工具包络均留在有效区域内。不能仅从 CAD 渲染认定表面气密，也不能用 50 的本体高度直接指定直径 50 的吸盘。吸附点还要结合实测重心、桌面间隙、相邻电池及目标位的侧向接近/撤离空间选择，不通过挪动规定初始位置来获得通道（RULES p2）。

侧吸的重力沿吸附面切向作用，且重心通常与吸附面存在法向偏距。实际真空度、抗滑及抗剥离力矩应分别核验；落台承重后泄压，确认脱离再沿侧面法向撤离。完整受力估算、硬件组成及与钩具的对比见 [末端两方案与侧吸设计](end-effector-options.md)，其中的计算仅为工程示例。

## 对传统视觉的影响

颜色用于选择目标，盒体外形与提手方向用于拟合位置和朝向。可先拟合带圆角的 70×80 外包络，并结合提手方向确定前后进钩轴；还需根据周围电池及工具包络选择有通道的一侧。必要时增加斜视观察位核验孔口，实际阈值和轮廓质量须用 D435i 实采数据验证。

侧吸路线在选定电池后还需确定所选侧面的法向和可吸附区域。正俯视图通常不能直接测出竖直侧面的深度平面；可增加能看见该面的斜视观察位，在有效深度区域拟合平面，或使用经实物核验的模型由主体位姿推算。后一种应标注为模型估计，无法确认侧面或通道时重新观察。吸盘朝向由侧面法向决定，接触高度不能套用提手孔口高度。

模型包含两个明显的高度层：本体顶面在底面以上 50，提手横梁顶面在底面以上 80；结合横梁高 10，横梁下沿的名义高度为 70。应分别选择本体顶面与提手顶部的有效深度区域，以实测孔口和钩具包络求进钩高度；整块同色区域的单一中值不能当作进钩高度。顶视图无法直接看到的横梁下表面，只能通过已核验模型推算或补充视角观察，不能标成直接深度测量。

内框评估使用电池主体在底图平面上的完整垂直投影。按图示直立模型，提手投影位于盒体外轮廓以内；采用主体圆角矩形投影建模时，不能把提手下面的开口从分母中扣掉，因为该位置下方仍有本体。末端斜视图中的可见色块面积不能直接代替桌面正投影面积。

具体相机到基座变换、停稳采图和释放复核流程见 [硬件与传统视觉方案](hardware-vision-plan.md)。

## 内框覆盖率的条件核算

规则输入：内框覆盖率为电池主体落在内框内的垂直投影面积除以主体总投影面积，门槛 ≥70%（USER-RULE-20260906-02，用户转述组委会答复）。外框仍要求主体完整位于框内（RULES p4）。

计算假设：电池直立，主体投影为宽 70、长 80、四角 R8 的圆角矩形；提手投影不超出主体；内框按 MAP p2 的圆形示意与 8×8 cm 注记解释为直径 80 的圆。坐标原点取内框中心，不计制造、印刷、测量和释放误差。图片单位及实物边界的核验结果会影响这些数值。

| 条件 | 工程计算结果 |
| --- | ---: |
| 主体投影面积 | 5545.06 mm² |
| 居中时与内框交集面积 | 4764.94 mm² |
| 居中覆盖率 | 85.93% |
| 保持朝向、仅沿 x（70 边）方向偏移，达到 70% 的边界 | 约 ±17.26 mm |
| 保持朝向、仅沿 y（80 边）方向偏移，达到 70% 的边界 | 约 ±18.19 mm |
| 同时取上述两个轴向偏移边界 | 覆盖率约 56.67%，低于门槛 |

这些是理想模型的几何边界，两个轴向界不能组合成一个允许误差矩形，也不能当成机械臂、视觉系统或整机的精度保证。实际控制应以中心为目标，根据观测误差与释放滑移留出覆盖率余量；圆角、有效框线和实际姿态测定后再计算可用容差。

两种末端方式下，上述直立模型均用于落台、工具完全脱离并稳定后的评估。钩取的摆动、侧吸的滑移或吸盘变形须另行观测，不能将搬运中的姿态或工具指令直接套入居中覆盖率结论。

计算方法：主体面积 `A_B = 70×80 − (4−π)×8²`。居中时圆角削去的部分位于圆形内框之外，可用解析式 `A_cap = 2×[35×sqrt(40²−35²) + 40²×asin(35/40)]` 交叉核对交集面积，反三角函数采用弧度。偏移时按 x 截面求圆与圆角矩形的竖向区间交集，以复合 Simpson 积分求面积、二分求 70% 边界；32,000 与 128,000 个积分区间得到的轴向边界差小于 0.000003 mm。该收敛量仅描述数值计算，不代表图片尺寸或实物的准确度。
