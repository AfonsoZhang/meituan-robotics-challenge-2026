## 三方案比较

| 项目 | 方案一：钩取提手 | 方案二：侧面吸盘 | 方案三：卡环 |
| --- | --- | --- | --- |
| 接触部位 | 从孔口穿入，承托顶部横梁 | 吸附本体的竖直侧面 | 环形件套住或卡住提手/本体的指定部位（对象待确认） |
| 必须验证的物体条件 | 提手通道、横梁与连接处承载 | 侧面可密封区域、气密性及抗滑接触条件 | 卡持对象尺寸、环内间隙、套入路径、承载与锁止面 |
| 工具候选 | 带上翘尖的固定被动钩，具体结构待定 | 单吸盘或多吸盘固定座，数量和布局由受力及空间验证决定 | 固定环、开口环或可开合卡环；是否主动闭合及是否带止退待定 |
| 姿态误差来源 | 挂点滑移、摆动、转动和钩具挠度 | 杯体压缩、切向滑移、偏心倾斜和局部剥离 | 环内间隙、卡环挠度、相对转动、碰撞和锁止回差 |
| 释放动作 | 落台卸载，下降清尖，水平退钩 | 落台承重，受控泄压，确认脱离后沿面法向撤离 | 落台承重后打开/退出卡环，确认完全脱离再撤离 |
| 附加设备 | 固定被动钩候选无需开合驱动 | 真空源、阀、管路、真空反馈及匹配接口 | 若为主动卡环，需要开合驱动或锁止反馈；被动卡环则需验证退出动作 |
| 路径要求 | 孔口侧的进入、退钩及钩尖避障空间 | 本体侧的接近、压缩、撤离及管路空间 | 环体套入/脱离的完整扫掠包络及防夹碰空间 |
| 共同验收 | 颜色、离台状态、放置误差、释放稳定性、完整序列成功情况及耗时 | 同左；真空达标仅是抓取判据之一 | 同左；卡环闭合或锁止状态不能替代视觉确认 |

三种方案均有适用条件。当前先做同一批实物的台架对比，再依据可重复的抓放表现决定最终工具；不能仅由“无需夹爪”或机构静态卡住决定优劣。

卡环不纳入本轮吸盘仿真范围。若需要在 Gazebo 中检查卡环的几何碰撞或路径，只建立无接触力学意义的几何占位；卡持、摩擦、锁止和释放可靠性以实物测试为准。

## 方案三：卡环草案

卡环暂定义为环形件套入或卡住提手横梁/本体指定部位，用户尚未指定卡持对象。候选形式包括固定闭环、带开口的被动环，以及带主动开合和锁止反馈的卡环；这些只是结构分类，不是已确认硬件。

设计约束是：环内尺寸须允许套入而又限制脱落，开口/闭合件不能碰撞本体或提手；工具扫掠包络须覆盖套入、承载、落台和退出全过程；承载时要核验提手或本体局部受力、环体挠度、回差和动态冲击。建议动作顺序为“外部预备位 → 对准卡持对象 → 套入/闭合 → 小幅试提并视觉确认 → 搬运 → 落台承重 → 解锁/退出 → 放后复核”。卡环的摩擦、锁止和释放可靠性只通过实物台架验证；本轮仿真最多做几何碰撞占位。

## 侧吸位置与机构草案

按直立姿态，定义 x 为本体左右、y 为前后、z 为向上。图示尺寸组成以下候选面（BATTERY-DRAWING，无 PDF 页码；图内未明示单位，暂按 mm 解释）：

| 候选吸附面 | 名义外包络 | 接近方向 | 限制 |
| --- | --- | --- | --- |
| 前面或后面 | 70×50 | 沿 y 方向朝向选定侧面 | 圆角、接缝及边界使连续平面小于外包络 |
| 左面或右面 | 80×50 | 沿 x 方向朝向选定侧面 | 同上；较宽不自动意味着更适合吸附 |

先在实物上找完整、连续的可密封区域，记录其宽高、边缘距离与表面状态。吸盘压缩后唇边须保持在区域内，并给定位误差留余量；不能直接按本体高 50 指定直径 50 的吸盘。CAD 渲染无法确认实际材料、孔隙、纹理、涂层或气密性。

建议结构为“法兰转接件 → 刚性侧向支架 → 吸盘及受限顺应连接”。压缩行程、预压力和侧向刚度由吸盘/支架实测确定，以能密封且不推移电池为目标；不假定 S3 已具备力控或末端力传感器。D435i 固定在法兰或工具刚性座上，避免跟随吸盘柔性部分变形。吸盘支架、接头和管路均纳入桌面及相邻电池的避障包络。

吸附点优先在可用面内保持合理边缘余量，再结合实测重心选择。把吸盘中心放到重心高度，并不能消除重心到侧面的水平力臂。单杯可作为台架样件；若倾斜或转动超出要求，再比较多杯或其他受约束结构。多杯的数量、间距和布置方向应针对实际力矩设计，水平并排两杯不自动消除重力引起的剥离趋势。

目标位除电池足迹外，还要有侧向撤离空间；三块依次摆放时，已经放好的电池也进入避障模型。初始位置按规定底图保持，不为获得侧吸通道自行移动电池（RULES p2）。

## 受力初筛与计算边界

真空提供法向吸附力，侧吸时还要承受沿面的重量及偏心力矩。Schmalz 给出静态理论式 `F_N = Δp × A_eff`，其中 `A_eff` 是真空下的有效面积，`Δp` 是环境压力与杯内压力之差；摩擦系数须结合实物确定。（[VAC-DESIGN：Schmalz 吸盘设计](https://www.schmalz.com/en-at/support/know-how/vacuum-knowledge/the-vacuum-system-and-its-components/vacuum-suction-cups/design-of-the-suction-cup)）

对密封稳定、仅考虑竖直切向载荷的简化工况，可作抗滑初筛：

```text
μ × Δp × A_eff ≥ S × m × (g + a_z)
```

这里 `μ` 为实测接触摩擦系数，`S` 为按工况确定的安全系数，`a_z` 为该竖直工况中使载荷增大的加速度，`m` 为工件质量；长度、压力与面积统一采用 SI 单位。依据为 Schmalz 的侧吸工况 III；完整运动还须检查水平加速、转动和减速的最不利载荷，不能仅用这一个式子验收。（[VAC-HOLD：Schmalz 理论保持力](https://www.schmalz.com/en-gb/support/know-how/vacuum-knowledge/the-vacuum-system-and-its-components/system-design-calculation-example/theoretical-holding-force-of-a-suction-cup)）

以下是本项目的静态算例，**不用于直接选定吸盘直径或真空阈值**：取 FAQ p5 的质量上限 `m = 0.25 kg`、`g = 9.81 m/s²`；仅为演示假设 `Δp = 40 kPa`、`μ = 0.5`、`S = 2`、`a_z = 0`。后三项设备/接触参数及安全系数均未被项目实测确定。

| 算例量 | 结果 | 使用限制 |
| --- | ---: | --- |
| 重量 `m g` | 2.4525 N | 未计运动惯性 |
| 抗滑所需有效总面积 `S m g / (μ Δp)` | 245.25 mm² | 仅是上述假设下的抗滑下界 |
| 面积等效圆直径 `sqrt(4 A_eff / π)` | 约 17.67 mm | 是有效面积等效值，不是采购公称直径；未校核力矩及变形 |

偏心还应单独核算 `M = |r × F|`；纯重力时简化为 `M_g = m g e`，其中 `e` 是重力作用线到吸附中心的水平力臂。本体水平重心若恰位于几何中心，则在上述两类侧面上可举例取 `e = 35` 或 `40 mm`，得到静态力矩约 `0.086` 或 `0.098 N·m`。这是基于重心假设的力学推算；实际提手、内部结构及材料分布未知，须测重心。

因此即使抗滑算例满足，也不能判定工具承载合格。须核对具体吸盘及连接件的侧向力、力矩适用范围并实测滑移和唇边翘起；不能把杯体柔性视为刚性连接。SMC 的布局说明也要求考虑重心、力矩及密封边界。（[VAC-SELECT：SMC 选型资料，PDF p5、p22](https://ca01.smcworld.com/catalog/BEST-technical-data-en/pdf/Vacuum-Common_en.pdf#page=22)）

选型时使用工作表面上实际建立的真空度和厂商有效面积/载荷数据，不用泵的极限真空或杯外径面积代替；若厂商额定值已含降额或安全系数，先核对定义，避免混算。本文保留具体型号、材质、数量、压力阈值和运动上限为空，待台架结果确定。

## 真空硬件与动作流程

| 部件 | 方案职责 | 尚需明确 |
| --- | --- | --- | --- |
| 吸盘与支架 | 形成密封、传递切向力与力矩 | 唇边材料/形状、数量、有效面积、尺寸、压缩量及额定负载定义 |
| 真空源 | 在实际漏气与管路条件下建立并维持真空 | 电动真空泵或气动发生器；后者需要匹配的压缩空气，现有供气未知 |
| 阀与管路 | 控制抽气、隔离和泄压 | 阀的状态定义、管路容积/漏气/压降、断电状态；停止泵不等于完成泄压 |
| 真空反馈 | 确认建立、监测搬运及释放 | 真空开关或压力传感器、安装位置、接口、阈值、滞回与超时 |
| 控制适配 | 接收机器人任务指令并返回状态 | 与实际 S3 控制柜或本机控制设备匹配；未确认 IO、电压或通信协议 |

先确认真空状态再提起，不能仅用固定等待时间代替反馈。该控制原则来自 SMC 选型资料 PDF p11；本项目另建议结合视觉试提确认，避免把堵管等情况下的真空读数误判为已带起电池。（[VAC-SELECT：SMC 真空确认](https://ca01.smcworld.com/catalog/BEST-technical-data-en/pdf/Vacuum-Common_en.pdf#page=11)）

```mermaid
flowchart LR
    A[观察目标侧面] --> B[沿法向接近并接触]
    B --> C[建立并确认真空]
    C --> D[试提及视觉确认]
    D --> E[保持吸附并搬运]
    E --> F[落台承重]
    F --> G[受控泄压并确认释放]
    G --> H[沿法向撤离及放后复核]
```

各阶段采用以下工程完成条件：

1. **观察与接近**：D435i 在有效观察距离停稳采图，识别颜色、物体位姿及可接近的侧面；正俯视不能直接验证竖直面的平面深度，必要时增加斜视。沿侧面法向接触，使用已验证的小压缩量，确认没有把轻质道具推走。
2. **真空建立与试提**：以台架结果设置真空阈值、稳定保持时间、滞回和建立超时；达标后小幅试提，以视觉确认电池离台并随工具移动。未达标或跟随不明确时不继续搬运。基础任务的离台稳定 2 秒按 RULES p3–4 保留。
3. **搬运与落台**：保持真空反馈，按已验证的加速度、姿态和路径搬运。出现真空不足或滑移时，不继续下一搬运段，执行已验证的停止/就近落台策略；异常状态机不得主动在悬空时泄压。
4. **释放与撤离**：确认电池在目标面承重后切断抽气并受控泄压，核验压力回升及实际脱离，再沿法向撤离。不要靠直接拉开仍吸住的吸盘脱离；若设备使用吹气破真空，先验证压力和时长不会吹移或带倒电池，不默认使用强吹气。
5. **放后复核**：工具完全脱离后确认电池稳定至少 3 秒，分别记录颜色/位次、内框投影覆盖率 ≥70%、外框完整包含；T0 保持原要求（RULES p3–4；内框采用 USER-RULE-20260906-02）。释放残余吸力或杯体回弹造成的位置变化计入误差。

三方案的手眼变换、停稳采图与软件分层见 [硬件与传统视觉方案](hardware-vision-plan.md)。更换工具需重新标定对应 TCP；相机相对法兰的固定关系变更时，重做手眼标定。

## 台架对比与选型依据

先核对实物和工具承载条件，进行台架验证，再接入 S3；目前未执行以下试验。用相同电池和目标位记录三种方案，保留每次成功与失败记录，不能只比较最好的一次。

| 次序 | 记录内容 | 决定什么 |
| --- | --- | --- |
| 1. 几何与表面 | 四块实物尺寸、质量/重心、孔口、连续吸附区、卡持对象和表面状态 | 哪些面和方向可进入、接触、撤离；三方案的物体条件是否满足 |
| 2. 静态承载 | 钩具/提手的承载、挠度和止退；侧吸真空建立时间、最低保持真空、滑移及倾斜 | 单次接合是否能稳定承载；侧吸建立超时及运行阈值的依据 |
| 3. 保持与释放 | 在台架支撑条件下测侧吸漏气/真空衰减；测落台脱钩或泄压撤离造成的位移 | 管路和真空源需求、故障处置时间余量、释放误差 |
| 4. 运动工况 | 逐步验证实际提起、平移、转向及减速；记录摆动、滑移、真空和耗时 | 该工具允许的运动范围与速度/加速度，单杯或多杯是否需要调整 |
| 5. 单块与完整序列 | T0 单块及不同测试口令下三块抓放，保存连续视频和全部结果 | 依据成功情况、最终落点、稳定性及耗时选择最终末端 |

具体重复次数和可接受误差在测量条件确定后设定；当前不声称任何成功率。无论使用哪个末端，内框覆盖的理想几何计算仍见 [几何分析](battery-geometry.md)，应使用落台释放后的实际姿态，保留测量与释放误差余量。
